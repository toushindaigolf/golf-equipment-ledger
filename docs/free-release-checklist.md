# 無料版リリース前チェックリスト

この文書は、無料版を一般公開する直前に、運営者本人が実環境で確認するためのチェックリストです。チェック前に本番相当のJSONバックアップを保存してください。

## 機能

- [ ] 用品を新規登録できる
- [ ] 登録済み用品を編集できる
- [ ] 登録済み用品を削除できる
- [ ] 文字検索を実行できる
- [ ] 並び替えを変更できる
- [ ] 購入総額、売却総額、実質支出額、所有アイテム数が正しい
- [ ] 「データを保存」から保存データファイルをダウンロードできる
- [ ] 未ログイン・端末内保存時に、保存データの読み込み前の確認が表示され、正しいデータを復元できる
- [ ] ログイン・クラウド保存時に、未対応の保存データ読み込みがクラウドデータを変更せず安全に案内される
- [ ] Supabase未設定・未ログインでも端末内保存を利用できる
- [ ] アカウントを作成してログインできる
- [ ] ログアウトできる
- [ ] ページ更新後も利用中の保存先にデータが残る
- [ ] Free／Pro表示がSupabaseのentitlementsと一致する
- [ ] FreeユーザーがPro機能を操作すると購入を促さない準備中案内が表示される
- [ ] 設定済みの問い合わせリンクを開ける
- [ ] 問い合わせURL未設定時に準備中表示となる

## データ安全性

- [ ] localStorageデータがログイン・ログアウトだけで削除されない
- [ ] Supabaseデータがログイン・ログアウトだけで削除されない
- [ ] 保存データファイルの内容と件数を確認した
- [ ] クラウド移行前に保存データファイルを作成できる
- [ ] 移行失敗時も端末内データが保持される
- [ ] 別ユーザーの用品データが表示・更新・削除できない
- [ ] equipment、profiles、entitlementsで必要なRLSが有効である
- [ ] `.env.local` がGit管理対象外である
- [ ] Supabase Secret key、Service Role Key、データベースパスワードがフロントエンド・Git・ログに含まれていない
- [ ] Googleフォームに秘密情報やパスワードを入力しない案内がある
