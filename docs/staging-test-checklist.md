# ステージング環境テストチェックリスト

## 環境とデプロイ

- [ ] Gitブランチが`staging`である
- [ ] Cloudflareのデプロイ種別がPreviewである
- [ ] `STAGING｜テスト環境`が表示される
- [ ] Preview URLに横スクロールが発生しない
- [ ] 本番URLにSTAGINGバナーが表示されない
- [ ] Production環境変数を変更していない
- [ ] PreviewのSupabase Project Refがテスト用である

## 認証

- [ ] テスト専用アカウントを作成できる
- [ ] 確認メールを受信できる
- [ ] Preview URLへ戻ってログインできる
- [ ] ログアウトできる
- [ ] ページ更新後もログイン状態が維持される
- [ ] 本番アカウントとテストアカウントが混在しない

## Free機能

- [ ] 未ログインで用品を登録・編集・削除できる
- [ ] 文字検索と並び替えが動作する
- [ ] 基本集計が正しい
- [ ] データを保存できる
- [ ] Pro機能が制限され、準備中案内が表示される

## Pro権限

- [ ] テスト用SupabaseだけでPro権限を付与した
- [ ] Pro表示、詳細分析、CSV出力、高度な絞り込み、データ移行が利用できる
- [ ] Freeへ戻すとPro機能が制限される
- [ ] 権限取得中にPro機能が先に表示されない
- [ ] 権限取得失敗時にFreeとして扱われる

## クラウド保存とRLS

- [ ] テスト用Supabaseへ用品を登録・再取得・編集・削除できる
- [ ] 別のテストユーザーの用品を取得できない
- [ ] 別のテストユーザーの用品を更新・削除できない
- [ ] ブラウザから`entitlements`を追加・更新・削除できない
- [ ] 本番Supabaseにテストユーザーやテスト用品が作成されていない

## データ移行

- [ ] テスト専用の端末内データを準備した
- [ ] 移行前に保存データファイルを作成した
- [ ] テスト用Supabaseへ移行できる
- [ ] 重複移行が発生しない
- [ ] 端末優先・クラウド優先・キャンセルを確認した
- [ ] 一部失敗後に再試行できる
- [ ] 元の端末内データが自動削除されない

## 問い合わせと表示

- [ ] Previewからテスト用問い合わせフォームが開く
- [ ] テスト送信が本番問い合わせと区別できる
- [ ] 360px、375px、390px、430px、768px、1280pxで表示した
- [ ] バナー、タイトル、操作ボタンが干渉しない
- [ ] 横スクロールが発生しない

## 最終確認

- [ ] `npm test`が成功した
- [ ] `npm run build`が成功した
- [ ] `git diff --check`が成功した
- [ ] `.env.local`などの秘密情報がGit管理対象外である
- [ ] Stripe設定、決済、Webhookを追加していない
- [ ] `main`へ自動マージまたはPushしていない
