# 無料版公開情報

この文書は、Stripe導入前に無料版を公開する際の、利用者向け表示と運用上の前提をまとめたものです。実際にアプリ内へ表示する利用規約・プライバシーポリシーは、フッターの各リンクから確認できます。

## 現在の無料版

無料版では、用品の登録・編集・削除、一覧表示、文字検索、並び替え、基本集計、保存データファイルの作成・読み込み、PWAとしての利用、アカウント作成・ログインを利用できます。

詳細な購入分析、カテゴリー・メーカー・ステータスを使った絞り込み、CSV出力、端末内データのクラウド移行は、Pro機能または準備中の機能です。Stripe決済、価格、定期更新、返金、解約は未実装であり、Pro版は購入できません。

## 保存先とログイン

ログインしていない用品データは、利用中のブラウザの端末内保存領域に保存されます。ブラウザのサイトデータを削除した場合、端末内データも削除される可能性があります。

ログイン後は、移行期間中のクラウド保存を利用できます。端末内の用品データは、ログインだけではクラウドへ移行されません。クラウド保存と複数端末利用の正式な提供条件は、Stripe導入・Pro正式提供の検討に合わせて変更される場合があります。

## データ削除の案内

端末内データは、利用者自身が「データを保存」で必要な記録を保管し、ブラウザ設定から本サービスのサイトデータを削除することで削除できます。削除後の端末内データは復元できません。

クラウド上の用品データやアカウントの削除は、アプリ内に一括・即時削除機能を設けていません。Googleフォームで、登録メールアドレスと削除対象を受け付け、本人確認後に個別対応します。運営者は、対応期限、本人確認手順、削除対象の範囲を運用として決めてから公開してください。

## 問い合わせフォーム

問い合わせ、不具合報告、改善要望、データ削除依頼はGoogleフォームで受け付けます。公開URLは環境変数 `VITE_CONTACT_FORM_URL` に設定します。値はブラウザに公開されるURLのため、Secret key、Service Role key、パスワード、決済情報などの秘密情報は設定しません。

問い合わせフォームには、パスワードや決済情報を入力しないよう案内します。削除依頼には、登録メールアドレスと削除対象を記載してもらいます。

## 利用する外部サービス

- Supabase：アカウント認証、移行期間中のクラウド保存、利用プラン情報
- Cloudflare Pages：Webアプリの配信
- Googleフォーム：問い合わせ・削除依頼の受付

## 公開前に決めること

- 運営者が「等身大ゴルフ」表記で公開することの最終確認
- Googleフォームの回答確認者、受付頻度、本人確認方法、削除対応の目安
- 利用規約・プライバシーポリシーの実運用との一致
- プライバシー表示、規約および削除対応についての専門家確認の要否
- Cloudflare PagesのProduction環境変数に問い合わせURLを設定するかの確認

本書は実装状況を説明する資料であり、法的助言ではありません。公開前に必要な法令・契約上の要件は、運用地域や事業形態に応じて確認してください。
